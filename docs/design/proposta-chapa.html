GrelhaHub

Chapa Direção visual para o painel do restaurante e o cardápio público

A marca já é cartunesca-séria e ninguém usou: o monograma é um GH feito inteiramente de listras de grelha, com uma barra âmbar de destaque. Existe até uma regra escrita — “a barra da ligadura sempre em cor de destaque diferente das demais”. Isso não é enfeite de logo. É o sistema de design esperando para acontecer.

A regra da marca vira a regra da interface: em qualquer grupo, exatamente uma barra é âmbar — a ativa. Estado do pedido, aba, etapa de preparo, item selecionado. Um único mecanismo, repetido em toda tela, e o usuário aprende a lê-lo uma vez só.

O plástico, nomeado

“Parece feito por IA” é um estilo reconhecível, e ele é reconhecível justamente por não decidir nada. Vale nomear os componentes para poder recusá-los em revisão de código.

Regras para revisão de código

CHAPA-01
Sombra é sólida e deslocada. Nunca borrada.

3 px em elemento interno, 5 px em cartão. box-shadow: 5px 5px 0. Se aparecer um raio de desfoque, é plástico.

CHAPA-02
Uma barra âmbar por grupo — nunca duas.

É a regra da marca virando regra de interface. Duas âmbares em tela significam dois “agora”, e o operador perde a referência.

CHAPA-03
Dado em mono, prosa em sans.

Preço, telefone, ID e status são mono com tabular-nums. Descrição é sans. A escolha da fonte já diz que tipo de coisa é aquilo.

CHAPA-04
Alvo de toque mínimo de 48 px na operação.

Acima dos 44 do RNF-010. Quem opera está de pé, com pressa, e às vezes com luva.

CHAPA-05
Sem cadeado em campo que a API não devolve.

RN-GER-012 — se o perfil não pode ver o custo, não há blur, cadeado nem “desbloqueie”. Fingir que o dado existe é mentir sobre o modelo.

CHAPA-06
Emoji não é ícone, e muito menos estado.

Status é selo com borda e cor. Emoji renderiza diferente em cada sistema e não tem contraste garantido.

CHAPA-07
Comemoração tem hora marcada.

Confete existe em exatamente um lugar: o fechamento de caixa batendo certo. Uma vez por dia. Em cada pedido salvo, vira brinquedo.

CHAPA-08
Movimento tem massa.

Botão afunda 3 px e a sombra some — apertar é físico. Nada de fade de 200 ms. E tudo cede a prefers-reduced-motion.

O que muda no código

Quase tudo cabe em tokens e três componentes. estilos-globais.css já tem a paleta; o que entra é a elevação sólida, a listra e a comanda. 

/* elevação — o coração da direção */
--elev-1: 3px 3px 0 var(--carvao);
--elev-2: 5px 5px 0 var(--carvao);
--traco:  2px solid var(--carvao);

/* a listra: uma barra âmbar por grupo */
.grelha i        { width: 5px; height: 20px; opacity: .28 }
.grelha i.feita  { opacity: 1; background: var(--laranja-brasa) }
.grelha i.ativa  { opacity: 1; background: var(--ambar-chama) }

/* botão com massa */
.btn:active { transform: translate(3px,3px); box-shadow: none }

Três componentes novos: <Grelha etapa={n} de={6} />, <Comanda /> e <Selo />. O resto é token.
